# AI Case Summarization: Developer Docs

Developer facing documentation for the maternal case summarization pipeline. This site is a hub; most of the source of truth content lives in the repository itself and is linked from here instead of duplicated.

> ⚠️ **Clinical disclaimer:** this project is a documentation assistant. It does not diagnose, predict risk, or make treatment decisions, and every summary is reviewed and signed off by a clinician. It is not a certified medical device.

> 🚧 **Status:** this project is in active solution design and prototyping. There is no published pipeline code or public API yet. See [Status and Roadmap](../README.md#status-and-roadmap) in the README for current progress.
